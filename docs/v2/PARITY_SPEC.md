### 2.1 Server state (must be identical)
There is one in-memory dataset per process (`State`, `server.py:38`). The default is `baseline`. Load and upload replace it for every client. The audit log is SQLite at `AUDIT_DB` (default `app/var/audit.db`), with one row per ask (`server.py:151-155`); persona is written as `"{resolved} (requested: {raw})"` when it differs. Sessions are in memory with a 15-minute TTL, a cap of 500 and session ids matching `^[A-Za-z0-9_-]{8,64}$`. Questions are trimmed to 500 characters.
### 2.2 Read-only and demo switches
`NP_READONLY_PUBLIC=1` makes load/upload return 403. `NP_DEMO=1` makes non-rules model runs return 409.
### 2.3 New JSON API for React
**None required.** Every screen is built from the endpoints above. If the bot adds helpers, they must be pure re-exposures under `/api/v2/*`, and the old paths stay unchanged. Serving changes: `/` serves the React index, `/assets/*` the build, and `/legacy` the old UI.
