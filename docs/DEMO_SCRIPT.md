# 90-second demo script

All values are illustrative synthetic data.

| Time | Do | Say |
|---|---|---|
| 0:00 | Open `index.html` on the **Executive view**, scenario *Baseline demo* | "Leadership sees only vendor MAU. This view shows an AI value score, always beside its five pillars." |
| 0:10 | Tick **Simulate critical-risk breach**, then untick. Tick **Simulate missing** on Outcome, then untick | "A breach flags the score red whatever its value. A missing pillar withholds the score: no silent guessing." |
| 0:20 | **How we count** → switch to logical-interaction counting | "Nine raw events are two real interactions. Vendor-style counting overstates usage 4.5 times." |
| 0:35 | **Adoption Insights Agent** → click **Q07** | "A why question gets a breakdown by funnel stage and team, the biggest contributor, an honest correlation caveat and next steps." |
| 0:50 | Click **Open cohort 2 funnel in Regional view** | "Every answer drills down to the governed dashboard." |
| 0:55 | Back in the agent, type a card number | "Unsafe or out-of-scope questions are refused, with a safe alternative." |
| 1:05 | Change **Scenario**: Healthy → Shelfware → Reliability incident → Critical-risk breach | "The same rules give a different renewal call: expand, right-size, remediate." |
| 1:20 | Switch **Viewing as** to Regional lead B, then to Platform engineer | "Row-level security: each persona sees only their scope." |
| 1:25 | **Governance** | "Owners, versions, tests and an audit trail of everything I just did." |

Or press **Guided demo** for the 6-step story (arrow keys work).
